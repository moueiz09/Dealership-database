# Dealership-database
dealership database implementation

# Business problem
Family owned dealership sells vehicles, new and used. Sales, inventory, and sales metrics (vehicles sold, revenue) are all tracked on paper, and is coming to be tedious and troublesome. Management is having trouble tracking inventory, sales team metrics, and records are getting lost. The database aims to fix these problems.

# Features
- New and used vehicle inventory
- Customers (includes buyers and potential buyers)
- Employees (Manager and sales team)
- Transactions
- Sales reports

# Database Choice
  DB Browser (SQLite)
